# Transportation LP Optimization

## Project Overview

This project combines demand forecasting and linear programming to optimize transportation costs across a regional grain distribution network. Using forecasted demand, mill capacity constraints, and shipping lane costs, a transportation model was developed in Python to determine the lowest-cost shipment plan while satisfying customer demand.

The analysis evaluates multiple business scenarios, including baseline operations, the financial impact of removing a production facility, and the value created by forecast-driven planning. Results were summarized through executive-level visualizations and business recommendations.

## Tools Used

- PuLP

## Business Questions

- What is the lowest-cost transportation plan?
- What is the financial value of the Wichita mill?
- How much value does forecasting provide to routing decisions?
- How efficiently are mill capacities being utilized?

## Key Findings

- Baseline transportation cost: $240,132 annually
- Removing the Wichita mill increases annual freight costs by $45,864
- Forecast-driven planning generated approximately $9,612 in annual transportation savings
- All customer demand requirements were satisfied while minimizing total shipping cost
